4. Graphic Background and Island Treatment Review

Low-ink preview of art usage recommendations

Use art by active island

Display the current island art as contextual identity, but mask it so controls remain readable.

Make true island cutouts

Batch-process square assets with irregular oval alpha masks, sand rings, and feathered surf.

Create wide crops

Dashboard backgrounds want 16:9 or 21:9 exports with protected focal points.

Modal-specific art

Use Education for training, Transport for market, Banker for finance, Doctor for medical details.

Normalize brightness

Preprocess day/night variants so contrast does not swing wildly by season.

Keep the map functional

Use the mini map for status/navigation; use art for atmosphere and island identity.
