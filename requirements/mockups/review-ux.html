Graphic Background Review

Use island art as contextual signal, not as a dim wallpaper that fights the UI.

Island-shaped treatment preview

Oval crop + beach ring + water falloff
Transport island as a navigable island tile
Night art with softened coast edge
Healthcare island without square boundaries

Use art by active island

Keep the current tab's island art in the main work area, but mask it with a left-to-right gradient so buttons and text stay readable. This makes the island identity obvious without turning the screen into an eye exam.

Add art thumbnails to tabs

For multi-role players, use a cropped 32px thumbnail or color strip in each role tab. It gives a quick visual anchor when switching between islands.

Create wide crops

The 1024 square images work, but dashboard backgrounds want 16:9 or 21:9 crops. Generate curated wide exports with protected focal points so important buildings are not clipped on desktop.

Make true island cutouts

Batch-process each square asset with an irregular oval alpha mask, a narrow sand-colored beach ring, and feathered surf. This removes the square breakwater feeling while keeping the generated buildings.

Separate modal backdrop art

People/training dialogs should lean on Education art; market dialogs can use Transport art; finance dialogs can use Banker art. The player gets context before reading a single word.

Normalize brightness

Some day images are much brighter than night images. Ship a CSS overlay per asset or preprocessed variants so the UI contrast does not change wildly by season.

Keep the map functional

The mini archipelago map should remain a navigation/status object. Use the art for atmosphere and identity, not as a replacement for the role/status map.
