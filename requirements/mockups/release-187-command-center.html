Release #187 Command Center

A proposed internal UX for capturing and executing the 0.1.5-beta.1 release outline: version reconciliation, release notes rollover, test evidence, promotion to master, and tag creation. This is deliberately process-focused; #187 is a release-cut item, not a gameplay feature requirement.

Design stance: make the release requirement editable, auditable, and hard to half-complete. The screen should feel like a checklist with teeth, not a decorative form wearing a tiny clipboard hat.
