# Island Traders — Claude Code Context

## What this project is

Island Traders is a Python-based board game (2–7 players) where each player governs an economic island, trading resources across seasons to accumulate the most wealth. It supports both digital play (CLI) and physical board game play (printable assets generated by the software). A simulation runner lets AI agents calibrate the event charts that govern seasonal yields, disasters, and outages.

The project was originally developed in the `ashersilver/kind` repo (a Kubernetes scratch repo) and has been moved here to `ashersilver/island-traders`.

## Key design decisions to preserve

**Currency**: called "Dollops" (symbol `Dp`), not "gold". Constants: `CURRENCY_NAME`, `CURRENCY_SYMBOL`, `STARTING_DOLLOPS = 100.0`.

**Farmer is seasonal**: Unlike all other roles, the Farmer uses `FARMER_SEASONAL_CONVERSION` (in `constants.py`) — a per-season input→output table that replaces `BASE_PRODUCTION`/`PRODUCTION_INPUTS` for that role. Spring/Summer produce more Fish; Autumn produces a bumper Food harvest.

**Workforce model**: Each island has a workforce with profession tiers (Unskilled → trained profession). Workforce size and skill mix scale production. Key constants: `STARTING_WORKFORCE`, `SEASONAL_WORKFORCE`, `STARTING_WORKERS_BY_PROFESSION`, `LABOUR_REQUIREMENTS`, `SKILLED_PROFESSIONS`.

**Doctor island workforce**: 6 total workers: 2 Doctors + 4 Nurses. `STARTING_TRAINED_FRACTION = 1.00` — all trained.

**University capacity**: Governed by `UNIVERSITY_CAPACITY` (per year per profession) and `UNIVERSITY_SEASONAL_CAP` (stricter per-season caps). Professors cap at 1/season.

**Production capacity floor**: `STARTING_PRODUCTION_CAPACITY` gives each island a minimum effective workforce factor from physical infrastructure — prevents production from hitting zero even with a thin workforce.

**Resources (11 total)**:
`Food`, `Fish`, `Ore`, `Oil`, `Freight`, `Knowledge`, `CapitalEquipment`, `Goods`, `HealthServices`, `Vaccine`, `Finance`

**7 islands and their trade flows**:
| Role | Island | Produces | Needs |
|---|---|---|---|
| Farmer | Agriculture, Fisheries & Foods | Food, Fish | CapitalEquipment, Oil |
| Miner | Mining & Oil | Ore, Oil | Oil, Freight |
| Transporter | Transportation & Shipping | Freight | Oil, CapitalEquipment |
| Educator | Education & Training | Knowledge | CapitalEquipment, Finance |
| Banker | Banking | Finance | Knowledge, CapitalEquipment |
| Manufacturer | Manufacturing | Goods, CapitalEquipment | Ore, Oil, Freight |
| Doctor | Healthcare | HealthServices, Vaccine | Knowledge, CapitalEquipment |

**Multi-role players**: `Player.roles` is a `list[Role]`. A player can hold multiple roles; inputs/outputs are summed across all roles each turn.

**Shared roles**: `RoleTeam` groups multiple players sharing one role. `RoleAssignment.sub_responsibilities` is free-text (not engine-enforced). `active_player_for_production()` nominates one player per season.

**Event chart calibration**: Edit `config/event_charts.yaml` weights, then run `python -m island_traders.simulation.runner --games 1000 --seed 42` and inspect the CSV. Target: win rates ≈ 1/7 across all roles.

## How to run

```bash
pip install -e ".[dev]"
pytest                                          # all tests
island-traders                                  # interactive CLI game
island-traders-sim --games 100 --seed 42        # simulation
island-traders-export --output ./printables     # printable assets
```

Open `island_traders/board/game_board.html` in a browser to view the full game board visualisation.
