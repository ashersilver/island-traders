# Island Traders

A Python-based resource-trading board game for 2–7 players. Each player governs an island built around a different economic sector — farming, mining, transport, education, banking, manufacturing, or healthcare. Over a series of seasons you produce resources, trade with other players, develop your workforce, and negotiate deals. The player with the highest total wealth at the end wins.

The software supports both **digital play** (interactive CLI) and **physical board game play** (printable role cards, event tables, and price boards generated by the export tool). A simulation runner lets you calibrate the event charts that govern seasonal yields, disasters, and outages.

---

## Quick install

```bash
git clone https://github.com/ashersilver/island-traders.git
cd island-traders
pip install -e ".[dev]"
```

Requires Python 3.9+.

---

## Play a game

```bash
island-traders
```

The CLI walks you through setup (number of players, role assignment) and then runs turn-by-turn play.

---

## Run the simulation

```bash
island-traders-sim --games 100 --seed 42
```

Runs N games with AI agents and writes a CSV of results to `simulation_results/`. Use this to check win-rate balance across the 7 roles.

---

## Generate printables

```bash
island-traders-export --output ./printables
```

Generates all physical board game assets — role cards, event tables, and the market price board — as text files in the output directory.

---

## Run tests

## Project layout

```
island_traders/
├── constants.py        # All numeric constants — tune game balance here
├── models/             # Core data: resources, roles, players, market, deals, workforce
├── engine/             # Game logic: production, trading, events, AI strategy, turn manager
├── simulation/         # Simulation runner for bulk playtesting
├── export/             # Printable asset generator
├── chat/               # SQLite-backed in-game chat (API, models, service, store)
├── board/              # HTML board visualisations
└── cli/                # Interactive CLI entry point
config/
└── event_charts.yaml   # Tunable event weights per island
tests/                  # pytest test suite
```

---

## Tuning the event charts

Edit the weights in `config/event_charts.yaml`, then run the simulation:

```bash
island-traders-sim --games 1000 --seed 42
```

Inspect the output CSV in `simulation_results/`. The target is roughly equal win rates (≈ 1/7 ≈ 14%) across all 7 roles. Adjust weights and re-run until balanced.
